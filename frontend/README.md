# CrawlIQ Frontend — Next.js 15, Tailwind CSS & TypeScript

Modern dark-theme dashboard for the **CrawlIQ** SEO auditing platform.

---

## 🛠️ Stack & Features

* **Framework**: Next.js 15 (App Router, Turbopack)
* **Language**: TypeScript
* **Styling**: Tailwind CSS & Lucide Icons
* **PDF Exporter**: `jsPDF`
* **Components**: SVG Arc Gauges, Dotted Crawl Velocity Bar Charts, Filterable Issue Diagnostic Cards, PageSpeed Core Web Vitals Gauge, Modal Controls.

---

## 🚀 Running the Frontend

```bash
# 1. Install dependencies
npm install

# 2. Start Next.js development server
npm run dev

# 3. Build production bundle
npm run build
```

Open `http://localhost:3000` to view the application in your browser.
